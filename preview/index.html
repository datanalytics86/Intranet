Preview de la Aplicación Web

👋 Bienvenido al Preview

Este es un preview estático de la aplicación web completa para gestión de solicitudes HES (Hojas de Estado de Pago). Todas las páginas son completamente funcionales en términos de diseño y navegación.

💡 Características principales:

  • Portal público para solicitudes HES
  • Dashboard administrador con gestión completa
  • Sistema de autenticación
  • Módulo de configuración
  • Diseño responsive y profesional
  • Exportación a Excel
